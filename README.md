# Python Chapter 9 — Practice Set

This repository contains my solutions to the **Python Chapter 9 Practice Set**.

The exercises focus on practical file-handling operations such as reading files, searching for words, updating file contents, working with multiple files, copying files, comparing files, wiping file contents, and renaming files.

## Questions Covered

### 1. Search for a Word in a File

Write a Python program to read the text from a file named `poems.txt` and determine whether it contains the word **"twinkle"**.

### 2. Update the Hi-Score

The `game()` function in a program allows a user to play a game and returns the score as an integer.

Read a file named `Hi-score.txt`, which may either be blank or contain the previous high score. Update the high score whenever the new score is greater than the previous high score.

### 3. Generate Multiplication Tables

Write a Python program to generate multiplication tables from **2 to 20** and write each table to a separate file.

Place the generated files inside a folder.

### 4. Replace a Word in a File

A file contains the word **"Donkey"** multiple times. Write a Python program to replace every occurrence of this word with:

```text
#####
```

Update the same file with the modified content.

### 5. Censor Multiple Words

Repeat Problem 4 for a list of words that need to be censored.

The program should replace each specified word with:

```text
#####
```

### 6. Search a Log File

Write a Python program to read a log file and determine whether it contains the word **"python"**.

### 7. Find the Line Number

Extend Problem 6 by finding the **line number** where the word `"python"` is present in the log file.

### 8. Make a Copy of a File

Write a Python program to create a copy of a text file named:

```text
this.txt
```

### 9. Compare Two Files

Write a Python program to determine whether two files are identical and contain the same content.

### 10. Wipe File Contents

Write a Python program to remove all the contents of a file while keeping the file itself.

### 11. Rename a File

Write a Python program to rename a file to:

```text
renamed_by_python.txt
```
